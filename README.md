# 준준 TRIP (foodtrip)

가족 휴양지·맛집 리스트를 PC/폰 겸용 지도 앱으로. 집(덕소)·숙소 기준 거리·경로, 여행 플래너, 네이버/카카오/구글 연동.
사이트: **https://butimsorry83.github.io/foodtrip/** (GitHub Pages, 저장소 `Butimsorry83/foodtrip`, 브랜치 `main` 루트)

## 1. 파일 올리기 (업데이트 방법)
1. **https://github.com/Butimsorry83/foodtrip/upload/main** ← 바로 업로드 화면
2. 바뀐 파일을 드래그 (같은 이름이면 자동 덮어쓰기)
   - 루트 파일(`index.html` `app.js` `style.css` `tokens.css` `README.md`) → 그대로 드래그
   - 하위 폴더 파일(`data/db.json`, `assets/…`, `photos/base/…`) → **폴더째** 드래그하거나, 저장소에서 그 폴더로 들어간 뒤 `Add file › Upload files`
   - 한 번에 최대 100개
3. 제목(커밋 메시지) 적고 **Commit changes** → 1~2분 뒤 사이트 **Ctrl+F5** (그래도 예전 화면이면 주소 끝에 `?v=2`)

**제목 짓는 법**: `무엇: 한 줄 요약` — 소문자 영문 접두어 + 콜론 + 한글 요약
| 상황 | 제목 예 |
|---|---|
| 앱 코드 수정 | `app: 플래너 숙소 기준 반영` |
| 디자인·CSS | `style: 다크모드 지도 반전` |
| 데이터 갱신 | `data: 좌표 수집 2026-11-01` |
| 사진 추가 | `photos: 남해 대표사진 3장` |
| 문서 | `docs: README 키 만료일` |

앱에서 저장(가고싶다·방문 기록 등)하면 `data/db.json`은 **자동 커밋**되므로 손으로 올리지 않는다. 손으로 db.json을 올릴 때는 앱을 먼저 닫아 충돌을 피한다 (충돌 시 앱이 3-way 병합하지만 수동 업로드가 덮어쓸 수 있음).

## 4. 구성
| 파일 | 역할 |
|---|---|
| `index.html` `style.css` `tokens.css` `app.js` | 앱 본체 (정적, 서버 無). 디자인 토큰은 `tokens.css` |
| `data/db.json` | **유일한 데이터 파일** — 앱에서 편집하면 GitHub API로 커밋. 휴지통(`trash`, 30일) 포함 |
| `assets/` `photos/base/` | 로고·계절 배경·여행 표지 / 휴양지 대표사진(한국관광공사) |
| `guide/template.html` | 간이 안내서 템플릿 (trip-guide-html v2와 같은 디자인, 글꼴 내장) |
| `vendor/` | Leaflet 1.9.4 + markercluster |
| `tools/bundle.py` | 오프라인 단일 HTML 빌드 → `dist/YYYY.MM.DD_준준TRIP.html` (`py tools\bundle.py`) |
| `tools/tourapi_*.py` | 관광공사 사진·좌표 수집 (PC) |
| `tools/test.mjs` | Playwright 기능 테스트 (`python3 -m http.server 8765` 후 `node tools/test.mjs`) |

바탕지도: OpenStreetMap 표준 타일 (CARTO가 2026-11부터 API 키를 요구해 교체). 다크모드는 타일 CSS 반전. 카카오맵은 바탕지도가 아니라 **장소 검색·좌표·주변 후보**에만 사용 (해외 지역 때문).

## 5. 동작 메모
- 거리·소요: 장소 나라에 맞는 거점 기준 (국내=집, 나트랑=Melia). 카카오 REST 키 있으면 실경로, 없으면 도로 추정. 좌표 없는 곳은 시·군 중심으로 "대략"
- 플래너: 목적지 시·군 + 숙소(동네/호텔) 지정 → 숙소 반경 안 휴양지 자동 선정 → 집 출발 · 숙소 숙박 · 마지막 날 귀가
- 여행 삭제: 여행 화면 하단 「여행 삭제」(두 번 눌러 확인) → 휴지통 30일
- 저장: 기기마다 토큰 1회. 다른 기기가 먼저 저장했으면 3-way 병합(내가 바꾼 필드만 겹침). 삭제는 휴지통 30일
- 좌표 수집: 설정 › TourAPI 행 › "앱에서 좌표 일괄 수집" (국내 카카오, 해외 OSM 1초/건)
- 우리 장소: 장소 추가 › 유형 「우리 장소」(본가·처가·단골 등) → 보라 마름모 핀, 찾기 「우리」 칸, 상세 「거점으로 등록」
- 상세 작은 지도: 거점→장소. 카카오 REST 실경로 받으면 도로 실선(국내만), 아니면 점선 직선. 누르면 찾기 지도로
- 플래너 동선: 날짜별로 출발→도착(집·숙소) 이동이 가장 짧은 묶음·순서로 배정, 오전 절반 → 점심(다음 장소 방향) → 오후 → 저녁. 3곳이면 오래 머무는 1곳 단독 + 가까운 2곳 묶음. 숙소가 집에서 멀면 집보다 숙소에 가까운 곳만. 식당은 「식당 반경」(1·3·5·10km) 안, 귀가하는 날은 복귀 시각 안에 현지에서 먹고 출발할 수 있을 때만 저녁(집 앞 저녁 X) · 저녁은 양식 제외 · 유명 맛집만 반경×3 예외(미슐랭·블루리본 태그 / 우리 ★5 / 네이버 방문자·블로그 리뷰 1,000+ / 구글 4.5·리뷰 1,000+)
- 플래너: 휴양지 선택 안 하면 추천 상위 자동 구성 · 「근처 관광지 새로 찾기」(국내 카카오 관광명소, 해외 구글) → + 추가 시 휴양지로 등록 · 실제 숙소는 저장 시 거점 목록에 추가(체크)
- 화면: 상단/하단 메뉴 홈 · 찾기 · 여행 · **기록** · 설정 · 홈 ☾/☀ 버튼으로 다크모드 바로 전환(설정과 연동)
- 플래너 국내/해외: 상단 토글. 기본은 지금 거점의 나라(덕소=국내). 해외는 나라 → 도시·지역 선택, 목록에 없는 도시는 「＋ 추가」(db.json meta.ovCities에 저장 → 가족 공유). 숙소 옆 ✕로 선택 해제. 일정 결과의 장소·식당 이름을 누르면 상세, 닫으면 일정으로 복귀
- 우리 가족 기록: 기록 탭은 **앨범**(사진 격자 · 장소·날짜·장수) → 누르면 글(장소·별점·한줄평 먼저, 사진 아래). 상세 「모아보기」/ 여행 「여행기」 → 월별 피드(사진 크게·넘김, 한줄평·메뉴·함께 간 사람), 종류·사람 필터, 기록 없는 방문지 목록에서 바로 「+ 기록」
- 다녀온 곳 지도 (기록 탭 위쪽): 국내 17개 시·도 색칠(방문 많을수록 진하게) · 세계 나라 색칠(가봤음 청록/계획 노랑) + 집→여행지 선 · 통계(시·도 ○/17, 해외 ○곳, 세계 %, 누적 이동 왕복 직선) · 아직 안 가본 시·도(저장 많은 순) · 배지 14종. 여행 나라·장소 좌표·방문 기록으로 **자동 계산** (추가 입력 없음). 경계: `data/geo-world.json`(Natural Earth 1:110m, world-atlas ISC) · `data/geo-kr.json`(통계청 2013 시·도, southkorea-maps)
- 지도 꾸미기: 다녀온 곳은 최근 기록 사진(없으면 대표사진) 동그라미 핀 · 몰린 곳은 「사진+숫자」 묶음(확대하면 펼침) · 핀 누르면 사진 카드(글 보기·상세) · 도 이름+방문 수 · 세계는 여행 표지 사진 핀 + 항로 곡선(계획은 흐르는 점선) · 마우스 휠 확대·축소
- 여행 일정 가져오기: 여행 탭에 **준준 안내서 HTML**(trip-guide-html)이나 **여행 JSON**을 끌어다 놓거나 「⇪ 일정 파일 가져오기」 → 미리보기(제목·도시·나라·일수·일정) → 「여행에 추가」. 같은 여행이 있으면 덮어쓰기 선택. JSON이면 장소도 등록·연결, 숙소는 거점 추가 선택. 여권·항공권·예약번호는 가져오지 않음 (메모 속 번호도 지움)
- 살았던 곳: 기록 탭 지도 「⌂ 살았던 곳」 → 이름·나라·기간(년)·주소 검색(국내 카카오 주소) → 지도에 ⌂ 번호 핀 + 이사 경로 점선 (db.json `lived`). 공개 저장소라 동·아파트 이름 정도 권장
- 성장 앨범: 기록 탭 「🌱 성장 앨범」 → 사람 선택 · 사진 올리기(촬영일 EXIF 자동, 없으면 파일 날짜) · 연도 띠 + 나이(생년만 저장, 연 나이) · 「▶ 연도순 재생」(전체 화면 2.8초 자동 넘김, ←/→/Space/Esc) · 방문 기록 사진은 크게 보기에서 「🌱 성장 앨범에 넣기」(같은 파일 재사용) · 사진 `photos/growth/연도/` (db.json `growth`, meta.family.birthYear)
- 지도 이름: 세계는 가봤음·계획 나라 「베트남 / VIETNAM」(명조 + 영문 색 띠), 나머지는 확대 시 옅게 · 국내는 도 이름 명조 + 방문 수 배지 · 동해·서해·남해
- 캐시: index.html이 `app.js?v=날짜`로 부름 → **코드 수정 시 index.html도 같이 올림** (버전 숫자가 바뀌어야 새 파일을 받음)
- 글꼴: 본문 Pretendard(jsDelivr CDN) · 제목·메뉴 Gmarket Sans(Bold는 CDN, 실패 시 `assets/GmarketSansMedium.woff`) · 장소 타이틀 Anton(Google Fonts)
- 애니메이션: 세계 항로 ✈ · 가본 도 차례로 색칠 · 통계 숫자 올라감 · 이사 경로 그려짐 · 기록 저장 스탬프 쾅 · 새 배지 꽃가루 · 성장 앨범 확대·이동 + 연도 전환 · 스크랩북 쪽 넘김 · 홈 계절 효과(벚꽃·반짝이·낙엽·눈) · 카드 떠오름. 기기 「동작 줄이기」 설정이면 모두 꺼짐
- 장소 타이틀: 여행 열 때 · 세계 지도 여행 핀 · 살았던 곳 핀 → 화면 가득 「NHA TRANG / VIETNAM · 2025.06.28 — 07.05 / 좌표」 1.8초 (누르면 바로 닫힘)
- 살았던 곳 검색: 국내 카카오 주소 · 해외 OSM(나라 지정 → 나라 이름 붙여서 → 전 세계 → 구글) · 못 찾으면 지도 직접 눌러 지정 · 나라 176개국
- 지구본: 기록 탭 지도 「🌐 지구본」 → D3 정사영(vendor/d3geo.min.js, ISC) · 자동 회전 · 끌어서 돌리기 · 휠/± 확대 · 가본 나라 색칠 · 항로(대권) + ✈ · 여행 표지·살았던 곳 사진 핀(누르면 장소 타이틀)
- 홈 배경: 홈 「🖼 배경 바꾸기」 또는 설정 › 배경 사진 고르기 → 계절별 기본 + 추천 5장(Unsplash 무료 라이선스, 링크로 불러옴) + 내 사진(2400px, photos/hero/) · 가족 공유(meta.hero)
- 살았던 곳 사진: 살았던 곳 편집에서 사진 올리기(촬영일 자동) · 사진 속 사람 고르면 성장 앨범에도 자동 추가 · 지도 핀이 사진으로 바뀌고 누르면 사진 카드·크게 보기
- 지난 여행 간단 추가: 여행 탭 「＋ 지난 여행 간단 추가」 → 제목·나라·도시/동네(위치 찾기)·기간·사진·함께 간 사람 → 일정 없이 저장 · 사진 첫 장이 표지 · 여행 화면 「📷 사진 추가」(모든 여행)
- 기록 → 여행 묶기: 방문 기록에 「마지막 날」 + 「✈ 여행으로도 묶기」(해외 장소 기본 체크) → 기간 겹치는 여행에 붙이고(간편 여행이면 기간 늘림) 없으면 「2019 Paris」 간편 여행 자동 생성 · 여행 화면에 기록 사진·「이 여행의 기록」 칩
